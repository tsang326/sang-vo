# Sang Vo

Personal freelance site for Vo Truong Sang (Sang Vo). Static HTML and CSS. No backend.

After GitHub Pages is enabled, the site is at:

https://tsang326.github.io/sang-vo/

## Enable GitHub Pages

1. Open this repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
4. Set **Branch** to `main` and the folder to `/` (root).
5. Save.

GitHub publishes the root `index.html` to the URL above. The same source setting works with `/docs` if the site files are moved into a `docs/` folder. This repo keeps them at the root.
